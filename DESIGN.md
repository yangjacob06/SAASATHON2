# Mandate — The right connection

Approved direction: **Direction 02** in `RESEARCH/mandate-brand-directions.html`, chosen by the user on 27 September 2026. The reference file is retained unchanged.

## Identity

An adviser connects borrower information, a considered summary and potential lenders. Two open, linked paths and two flax endpoints form the mark. The identity expresses connection and adviser judgement; it does not imply automatic matching, lender approval or a credit offer.

Shared assets: `MODEL/prototype/assets/brand/`. Both the marketing/pitch prototype and the saved product workspace load `brand.css` from this directory.

| Role | Colour |
| --- | --- |
| Core identity, headings, primary actions | Deep teal `#244947` |
| Supporting strokes, revenue charts | Mid teal `#4E7C77` |
| Selected states, supporting surfaces | Sea glass `#BFE0D4` |
| Connection endpoints, restrained highlights | Flax `#E4D28B` |
| Page | Warm paper `#F6F6F1` |
| Secondary surface | Mist `#EAF1EF` |
| Body secondary text | `#526B65` |

Use dark teal text on sea glass and flax, never white small text on these light fills. Preserve distinct warning/error states and their explicit labels. Dark mode uses deep teal surfaces and sea glass actions. Print reports use the light palette.

## Typography

- Manrope, 600–750: headings and logo lettering.
- DM Sans, 400–700: product text, forms, tables and controls.
- Locally hosted WOFF2 files; original variable TTFs and SIL Open Font Licences included.
- Logo SVG lettering is outlined, so it does not depend on installed fonts.
- The dependency-free PDF renderer retains standard Helvetica body text for portable reports; its header uses the same outlined Manrope logo.

## Composition and imagery

Use generous whitespace, aligned comparison columns, restrained borders and 12px card radii. Connected paths, overlapping circles and small endpoint annotations are the image system. Use them at the marketing hero and meaningful workflow sequences; keep data tables and review decisions free of decorative lines. No approval badges or unlabeled scores in brand imagery.

The marketing illustration explains borrower → adviser review → potential lenders. The review workflow and lender cards retain their existing actions and meaning. Keep subtle lender-card hover movement and respect reduced motion.

## Scope

This branding changes presentation only. CSV parsing, review gates, confirmation signatures, criteria fit calculations, saved records and reporting contents retain their existing behavior. No API implementation or deployment is included.
